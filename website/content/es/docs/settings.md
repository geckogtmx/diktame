# Referencia de Ajustes

Haz que **dIKta.me** sea verdaderamente tuyo.

## Accediendo a los Ajustes

Haz clic derecho en el pequeño **icono de la bandeja del sistema** cerca del reloj de Windows y selecciona **Settings (Ajustes)**.

## El Recorrido

### 1. General (General)
Lo básico.
- **Language (Idioma)**: Inglés o Español.
- **Start with Windows (Iniciar con Windows)**: Enciende esto para que dIKta.me siempre esté listo al encender tu PC.
- **Sound Feedback (Sonidos del Sistema)**: El pequeño "bip" cuando empieza a escuchar. Apágalo si prefieres el modo sigiloso.
- **Theme (Tema)**: Claro, Oscuro, o igual al del sistema.

### 2. AI Engine (Motor de IA)
Este es el cerebro de la operación.
- **Ears / Oídos (STT - Texto a Voz)**: ¿Quién te está escuchando?
  - **Cloud (Nube)**: Más rápido y sencillo. Requiere internet.
  - **Local**: Privado, sin conexión. Requiere una gran descarga inicial.
- **Brain / Cerebro (LLM - Modelo de Lenguaje)**: ¿Quién está pensando?
  - **Gemini / OpenAI**: Más inteligente, requiere internet.
  - **Ollama**: Se ejecuta localmente en tu propio equipo.

### 3. Modes (Modos)
Ajusta cómo se comporta cada modo. ¿Quieres que el **Dictado** sea rápido pero que **Refinar** sea inteligente? Aquí es donde lo configuras.

### 4. Audio
- **Microphone (Micrófono)**: Elige el correcto (¡no uses el micrófono de tu cámara web por accidente!).
- **Audio Ducking (Atenuación de Audio)**: Un término elegante para "bajar el volumen de mi música mientras hablo". Altamente recomendado.
- **Input Level (Nivel de Entrada)**: Una pequeña barra que rebota para demostrar que podemos escucharte.

### 5. Privacy (Privacidad)
Tus datos, tus reglas.
- **Ghost Mode (Modo Fantasma)**: Olvidamos todo al instante.
- **Stats Only (Solo Estadísticas)**: Contamos palabras, pero no las guardamos.
- **Balanced (Equilibrado)**: Guardamos lo suficiente para ser útiles (como el historial), pero limpiamos cosas sensibles.
- **Full (Completo)**: Guarda todo. Útil para buscar errores.

**PII Scrubbing (Limpieza de Información Personal)**: Este robot intenta censurar números de teléfono y correos electrónicos automáticamente.

### 6. API Keys (Claves API)
Las llaves del reino. Si usas el modo Cloud (Nube), pega tus claves `sk-...` o `AIza...` aquí. Las encriptamos para que se mantengan seguras.

### 7. Ollama
Para los héroes locales. Administra tus modelos de IA descargados aquí.

### 8. Control Panel (Panel de Control)
A veces quieres ver lo que pasa bajo el capó. Alterna los elementos del **HUD** (Pantalla de visualización frontal) aquí.
