# Ups (Oops)

El comando **Oops (Ups)** es una tecla especializada en dIKta.me diseñada para salvarte de inyecciones erróneas o errores de formato.

Debido a que dIKta.me inyecta el texto directamente en tu ventana activa, hay veces en que tu cursor podría estar en el lugar equivocado cuando ocurre la inyección. Podrías haber hecho clic en otro canal de Slack mientras el LLM procesaba tu dictado, y de repente tu párrafo perfectamente formateado termina en un lugar donde no corresponde.

## Cómo usar Ups (Oops)

Para arreglar un error de inyección, simplemente presiona la tecla de **Oops**:

`Ctrl + Alt + V` (Predeterminado)

El Inyector de Texto de dIKta.me siempre guarda de forma segura el *último fragmento de texto* que inyectó en la memoria. 

Si tu inyección terminó en el lugar equivocado, simplemente puedes:
1. Presionar `Ctrl + Z` en tu teclado para deshacer el error en esa aplicación.
2. Hacer clic donde *debería* haber ido el texto.
3. Presionar `Ctrl + Alt + V`.

El Inyector de Texto volverá a pegar instantáneamente exactamente el mismo texto con el formato correcto en tu posición actual del cursor, para que no tengas que dictar el párrafo entero de nuevo.

> [!NOTE]
> La memoria de Oops es volátil. Solo recuerda la última inyección realizada y se borra por completo cada vez que reinicias la aplicación de dIKta.me.
