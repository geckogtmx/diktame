# Fragmentos de Voz (Voice Snippets)

Los **Fragmentos de Voz (Voice Snippets)** son tu arma secreta para la velocidad. Convierten frases cortas en bloques largos de texto o comandos complejos.

## ¿Qué es un Fragmento (Snippet)?

Es una asignación: **Frase Activadora** → **Contenido Grande**.

Cuando estás dictando, dIKta.me escucha estos activadores. Si escucha uno, lo intercambia al instante.

## Usos Geniales

### 1. Firmas y Plantillas
Deja de escribir la misma despedida de correo electrónico 50 veces al día.
- **Tú dices**: "Insertar Firma"
- **Nosotros escribimos**:
  ```text
  Saludos cordiales,

  **John Doe**
  Desarrollador Senior | Equipo de Arquitectura
  *Enviado vía dIKta.me*
  ```

### 2. Instrucciones para la IA
Dile a la IA *cómo* escribir, no solo *qué* escribir.
- **Tú dices**: "Corregir Gramática"
- **Nosotros enviamos**: "Reescribe la última oración para que sea más profesional y corrige cualquier error gramatical."

### 3. Atajos para Desarrolladores
- **Tú dices**: "Git Push"
- **Nosotros escribimos**: `git push origin main --force-with-lease`

## ¿Cómo añado los míos?

Dirígete a **Ajustes > Snippets**.
Mantén tus activadores únicos (por ejemplo, usa "Mi Correo" en lugar de solo "Correo") para no activarlos accidentalmente durante una conversación normal.
