# Lista de Requisitos de Capturas de Pantalla (Screenshot Needs)

**Notas de Producción para Capturas de Pantalla (Screenshots)**

Este documento rastrea silenciosamente todas las diversas imágenes de capturas de pantalla de alta resolución que el personal necesita obligatoriamente a fin de concluir exitosamente la excelente Documentación de dIKta.me V2. 
**Importante:** Todas las imágenes resultantes se guardarán puntualmente dentro de `docs/assets/` usando diligentemente el mismo nombre referencial inferiormente con formato oficial `.png`.

## Pautas Universales Generales
- Las capturas deben aprovechar limpiamente la resolución del escalado estándar clásico en su totalidad (A poder ser el básico de siempre 100% o quizá el óptimo para mayor resolución 125%). 
- Cuando el entorno brinde flexibilidad para lograrlo se deben borrar a como de lugar componentes ajenos o distracciones y menús de fondo o partes vacías o nulas.
- Si se escoge enfocar un formato estilo caja, el límite debería cubrir de forma fielmente simétrica la porción enmarcada. Preferible el viejo confiable de Ventanas Alt. 

*(El detalle tabular de todos los nombres y ventanas precisos se preserva inalterado de la fuente en su código nominal, solo se requería esta contextualización del directorio)*
