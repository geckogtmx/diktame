# Getting Started

Welcome! Let's get you set up with **dIKta.me**. It’s simpler than you think—no coding or complex installations required.

## 1. Installation

Since V2 is a native Windows app, it just works.

1.  **Download**: Grab the latest `DiktaMe_Setup.exe` from our [Releases page](https://github.com/geckogtmx/diktame/releases).
2.  **Run**: Double-click the installer.
    > *Heads up: Since we're a new app, Windows might ask if you trust us. Click "More info" -> "Run anyway" to proceed.*
3.  **Done**: dIKta.me will launch automatically and settle into your system tray.

## 2. First Run Wizard

The first time you open dIKta.me, we'll walk you through a quick setup:

- **🎙️ Mic Check**: Pick your microphone. We'll show you a little level meter so you know you're being heard.
- **🧠 Brain Check**: Choose your AI.
    - **Cloud Mode**: Easiest way to start. Just need an API key.
    - **Local Mode**: Great for privacy buffs. Uses Whisper/Ollama on your own machine.
- **✅ Permissions**: We'll ask for permission to listen (when you say so) and type (where you tell us).

## 3. How to Use It

Think of dIKta.me as a quiet assistant living in your system tray.

- **To Dictate**: Click anywhere you can type and press **`Ctrl+Alt+D`**. Ideally, hold it down while you talk, like a walkie-talkie.
- **To Stop**: Just let go. We'll type out what you said.
- **To Tweak**: Right-click the little tray icon to change settings anytime.

That's it! You're ready to talk.
