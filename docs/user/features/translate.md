# Translate Mode

**Translate Mode** breaks language barriers. Speak in one language, and dIKta.me types in another.

> **Currently Supported**: English ↔ Spanish.

## How it Works

1.  **Hotkey**: Press **`Ctrl+Alt+T`**.
2.  **Speak**: Say something in English or Spanish.
3.  **Release**: That's it.

## Examples

- **You say**: "Hola, ¿dónde está la biblioteca?"
- **We type**: "Hello, where is the library?"

- **You say**: "I would like to order two tacos, please."
- **We type**: "Me gustaría pedir dos tacos, por favor."

It detects the language automatically, so you don't even have to switch settings. just talk.
