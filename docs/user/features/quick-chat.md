# Quick Chat

**Quick Chat** is your floating AI sidekick. It's perfect for when you need a quick back-and-forth without opening a browser tab.

## How it Works

1.  **Hotkey**: Press **`Ctrl+Alt+C`**.
2.  **Chat**: A small window pops up.
    - **Type**: Use it like any chat app.
    - **Talk**: Click the mic (or hold Space) to dictate.
3.  **Close**: Hit `Esc` or click away. The window vanishes.

## Why use it?

- **"Draft this email for me..."**
- **"Explain this code snippet..."**
- **"What does this error mean?"**

It stays on top of your windows, so you can reference your work while chatting. And by default, it clears its memory when you close it, keeping your workspace (and mind) clutter-free.
