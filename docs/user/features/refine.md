# Refine Mode

**Refine Mode** is your personal editor. It takes what you wrote (messy or not) and makes it shine.

## How it Works

1.  **Select**: Highlight some text you want to fix.
2.  **Hotkey**: Press **`Ctrl+Alt+R`**.
3.  **Go**:
    - **Autopilot**: Just let go immediately. The AI will fix grammar, spelling, and style.
    - **Instruct**: Hold the keys and say something like *"Make this professional"* or *"Translate to Spanish"*. Release to see the magic.

## Real World Examples

| You Have | You Say | You Get |
|----------|---------|---------|
| "i gonna go store" | *(Nothing)* | "I am going to the store." |
| "Hi boss, I quit." | "Make it polite" | "Dear Supervisor, I am writing to formally resign..." |
| "def foo(x): return x" | "Add docstring" | *(Adds Python docstring to code)* |

## Dual Personality

You can set up a different AI brain for **Refine** than you use for **Dictation**. Maybe you want a super-fast model for typing, but a genius-level model for editing. That works!
